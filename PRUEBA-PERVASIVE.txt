PRUEBA DE INTEGRACIÓN PERVASIVE (CHECADOR 2.0)
=================================================

Objetivo
--------
Validar que, al descargar registros en Admin SQL, también se inserten/actualicen
en Pervasive (tabla TIME_ATTENDANCE) con:
1) EMPLOYEE en formato 5 dígitos (ej: 00010)
2) IN_TS_MIN / OUT_TS_MIN en minutos desde 01/01/1968 00:00:00
3) Sin uso de EMP_IN_PROCESS_G

Dónde verlo en la app
---------------------
1. Abrir Checador.Desktop
2. Ir a "Admin SQL"
3. Clic en "Descargar Registros"
4. Revisar bitácora (parte inferior):
   Debe aparecer un texto como:
   "Espejo Pervasive OK. Insertados: X, actualizados: Y, omitidos: Z."

Si aparece "Espejo Pervasive deshabilitado", revisar appsettings:
- PervasiveSync.Enabled = true

Configuración activa esperada (Desktop appsettings)
---------------------------------------------------
PervasiveSync.ConnectionString =
  Driver={Pervasive ODBC Unicode Interface};ServerName=OCISERVER;DBQ=GLOBALOCI;UID=GLOBALOCI;PWD=GLOBALOCI;

PervasiveSync.Enabled = true
PervasiveSync.AttendanceTable = TIME_ATTENDANCE

Regla de conversión usada
-------------------------
PervasiveEpoch = 1968-01-01 00:00:00

IN_TS_MIN  = (FechaHoraEntrada - PervasiveEpoch).TotalMinutes
OUT_TS_MIN = (FechaHoraSalida  - PervasiveEpoch).TotalMinutes

Notas:
- Se redondea a 4 decimales.
- Si el cálculo diera negativo, se fuerza a 0.

Formato de EMPLOYEE
-------------------
Se guarda con 5 dígitos (padding izquierda con ceros):
- 10    => 00010
- 245   => 00245
- 99999 => 99999

Pruebas SQL rápidas en PSQL
---------------------------
(1) Últimos cambios:
SELECT TOP 30
  EMPLOYEE, CHARGE_DATE, IN_TS_MIN, OUT_TS_MIN,
  DATE_IN, TIME_IN, DATE_OUT, TIME_OUT,
  NAME, DEPT, SHIFT, CLOCKED_IN,
  DATE_LAST_CHG, TIME_LAST_CHG
FROM TIME_ATTENDANCE
ORDER BY DATE_LAST_CHG DESC, TIME_LAST_CHG DESC;

(2) Validar un empleado y fecha (ejemplo empleado 00010, fecha 20260306):
SELECT
  EMPLOYEE, CHARGE_DATE, IN_TS_MIN, OUT_TS_MIN,
  DATE_IN, TIME_IN, DATE_OUT, TIME_OUT,
  NAME, CLOCKED_IN
FROM TIME_ATTENDANCE
WHERE EMPLOYEE = '00010'
  AND CHARGE_DATE = '20260306';

(3) Conteo de hoy:
SELECT COUNT(1) AS RegistrosHoy
FROM TIME_ATTENDANCE
WHERE CHARGE_DATE = '20260306';

Checklist de aceptación
-----------------------
[ ] Admin SQL muestra "Espejo Pervasive OK"
[ ] EMPLOYEE se ve con 5 dígitos
[ ] IN_TS_MIN/OUT_TS_MIN crecen como minutos absolutos (no minutos del día)
[ ] Los cambios aparecen en TIME_ATTENDANCE tras cada descarga
[ ] No hay dependencia de EMP_IN_PROCESS_G en este flujo

Observación
-----------
Si no escribe en Pervasive y la app arranca bien, revisar permisos del usuario
(UID/PWD) sobre TIME_ATTENDANCE para INSERT/UPDATE.
